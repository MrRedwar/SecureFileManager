# Графические ресурсы приложения

Источник: комплект, предоставленный пользователем специально для Secure File Manager;
карта и указания — design/ASSETS_README.md. Новых изображений/шрифтов и сторонних
источников на этапе 03 не добавлялось. Системные шрифты не включаются в репозиторий.

Все исходные PNG успешно декодированы; фактическая инвентаризация (размеры, байты,
диапазон alpha) — screenshots/stage03/asset-inspection.txt.
Встроены 18 файлов Wpf/Assets с Build Action Resource. Их SHA256 совпадают с оригиналами.
16 имеют прозрачность, обе текстуры непрозрачны. Общий лист 1448×1086 только исходник
и в сборку не включён; полный концепт также не включён.

Иконки исходно 256×256; логотип/текстуры 1254×1254; Анубис 1086×1448;
оба орнамента 2172×724. Ресурсы доступны через стабильные component pack URI,
например /SecureFileManager.Wpf;component/Assets/icons/files.png.

Чтобы полезная часть не терялась на больших полях, Icons.xaml использует
CroppedBitmap/SourceRect по области заметной непрозрачности (alpha ≥128) с запасом
8 px. Это **кадрирование при отображении**, не перезапись исходных PNG:
слабые полупрозрачные артефакты вне рамки не выводятся, оригиналы сохранены.
Пропорции рисунка сохраняются через Uniform. Для текстур UniformToFill сохраняет
пропорции с обрезкой краёв, без повторяющихся швов.

Отсутствующих/повреждённых файлов не обнаружено, временных замен не понадобилось.
После замены исходных файлов отдельно обновить копии Assets, SourceRect и проверку;
автозагрузчиков/сетевых источников в приложении нет.
