# Артефакты WPF этапа 03

PNG с суффиксом **render** — экспорт реального визуального дерева WPF через
RenderTargetBitmap в STA-тесте. Это не фотографии desktop-окна и не изображения
концепта. Окно создаётся и показывается вне видимой области рабочего стола для
применения реальных шаблонов/перерасчёта колонок. Файловых/demo-данных в рендерах нет.

| Префикс | Экран |
|---|---|
| 01 | Диски |
| 02 | Мои файлы |
| 03 | Архивы |
| 04 | JSON / XML |
| 05 | Журнал |
| 06 | Настройки |

Для каждого экрана сохранены 1440×900 и 1024×640 DIP при экспорте 96 DPI (12 PNG).
Ещё два files-…-150pct-render.png экспортированы при 144 DPI:
1536×960 и 2160×1350 пикселей для тех же логических размеров.
Масштаб экспорта **не является проверкой системного DPI Windows**.

- asset-inspection.txt — исходные размеры, байты, диапазон alpha и границы всех PNG.
- live-window-accessibility.txt — дерево доступности итогового desktop-приложения.
- persistence-regression.txt — read-only состояние рабочей БД после изменений.
- Полная матрица ручных проверок: ../../STAGE03_REPORT.md.
