# WPF-рендеры этапа 07

02.11.2026. RenderTargetBitmap реальных XAML/ResourceDictionary с явно TEST-данными.
Это не desktop-снимки и не подтверждение системного DPI/ввода/аутентификации.

Сохранены шесть разделов в 1440×900/1024×640, прежние редакторы/формы для регрессии,
ZIP preview безопасного/опасного примера в 900×620/600×440, выбор назначения 600×440.
150pct означает экспорт с 144 DPI, а не изменение настроек Windows.

Компактные архивы/предпросмотр/назначение просмотрены визуально. STA проверяет DI aliases,
мультивыбор/команды, отключение распаковки опасного ZIP и минимальную высоту таблицы.
В тестовом Application остановлен только автоматически поставленный constructor startup,
чтобы обработка dispatcher layout не запускала production-вход; реальный App.xaml/DI/Views используются.
Интерактивную приёмку выполнять по docs/STAGE07_MANUAL_TEST.md.
