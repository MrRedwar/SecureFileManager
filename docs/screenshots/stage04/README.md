# Рендеры WPF для этапа 04

Это 22 PNG, сформированные RenderTargetBitmap в Windows xUnit, **не снимки рабочего
стола и не доказательство ручной приёмки**. Картинки включают клиентскую область;
внешняя рамка/DPI рабочего стола не захватываются, снизу возможен отступ до размеров окна.

- 01–06: шесть разделов в 1440×900 и 1024×640 DIP (12 PNG).
- files-*: «Мои файлы», вывод в 150% плотности (2 PNG).
- login-*/register-*: две формы, 640×760 и 520×600 DIP, плотность 100%/150% (8 PNG).

ТЕСТ_визуальный_рендер — явно тестовая сессия только из WpfShellTests, не реальный
аккаунт приложения. Таблицы пусты, SQL-данных в рендерах нет. В auth-рендерах
«соединение не проверено» соответствует UI fixture, которая не подключается к SQL.
Настоящий запуск отдельно подтверждён через UI Automation с успешным статусом БД.

Фактическое Windows DPI, Enter/Tab, системные кнопки и полный интерактивный сценарий
входа/выхода нужно принять по docs/STAGE04_MANUAL_TEST.md. Автозахват desktop-окна
вернул window capture timed out, ввод — coordinate input geometry is unavailable.
