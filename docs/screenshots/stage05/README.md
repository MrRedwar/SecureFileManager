не desktop capture и не доказательство ручного входа/DPI.

TEST-fixture — две явно тестовые строки и тестовая сессия; они существуют только в тесте,
приложение не содержит demo/seed файлов.

Палитра/ресурсы прежние. Промежуточные root PNG сохранены как артефакты итераций;
сравнивать итог нужно по final/02-1024x640-render.png и final/files-TEST-fixture-render.png.
Фактические диски/операции проверяются серверами в тестах и вручную по STAGE05_MANUAL_TEST.md.
