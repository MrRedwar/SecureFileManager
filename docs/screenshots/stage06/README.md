# Рендеры WPF этапа 06

02.11.2026. Это RenderTargetBitmap реальных WPF Views/Resources с явно тестовыми
данными, не desktop-скриншоты и не доказательство системного DPI/интерактивного входа.
`150pct` означает экспорт с 144 DPI, а не изменение масштаба Windows.

29 PNG: шесть разделов в 1440×900/1024×640 (12), Files при 150% (2),
Files с TEST-строками (1), Login/Register в двух размерах и двух масштабах (8),
TXT/JSON/XML editor в 860×660/600×440 при 150% (6).
Редактор рендерится по Content без внешней системной рамки; прозрачные поля Content
могут выглядеть чёрными в просмотрщике PNG. Окно имеет явный песочный Background.

Визуально просмотрены компактные JSON/XML/TXT редакторы и раздел JSON/XML 1024×640;
обнаруженный тёмный наследуемый фон редактора исправлен. Отсутствие binding errors,
dirty state/команды, сохранение исходных LF в TextBox и фильтр раздела проверены STA-тестом.
Native resize, focus, системные диалоги и повторное открытие одного редактора проверяются вручную.
