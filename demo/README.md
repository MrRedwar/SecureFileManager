# Явные демонстрационные данные

Только искусственный учебный текст, не копия рабочего Storage. Автоматического seed нет.
Импортируйте выбранные файлы через приложение в новую личную папку `defense-<дата>`.
Не копируйте их напрямую в Storage: это обходит создание Files и аудит.

| Файл | Назначение |
|---|---|
| example.txt | UTF-8, русский текст, редактирование/импорт |
| example.json / example.xml | валидные документы для проверки и сохранения |
| invalid.json / invalid.xml | маленькие синтаксические ошибки; можно открыть и исправить, Save блокируется до исправления |
| forbidden-dtd.xml | безвредная внутренняя entity, никаких файлов/URL; запрет DTD должен сработать уже при открытии |
| zip-input/first.txt, zip-input/second.txt | маленькие исходники для архива |
| safe.zip | обычный ZIP этих двух файлов для импорта/preview/extract |

Для показа ZIP Slip используйте существующий маленький `docs/test-data/stage07/unsafe-path.zip`
по инструкции того этапа, только через проверку приложения в изолированной области.
Не распаковывайте его Проводником/другим архиватором. ZIP Bomb не создаётся:
лимиты показываются через существующие ZipEngineTests с малыми безопасными данными.
Не публикуйте настоящие учётные данные или содержимое Storage вместе с demo.

Полный сценарий: [DEMO_SCENARIO](../docs/DEMO_SCENARIO.md).
